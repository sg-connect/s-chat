# Task 6 — Build PIN and family entry screens

Create the mobile-first `/family` flow for checking access, entering the family PIN, handling incorrect or limited attempts, entering a display name, and logging out.

Implement this as a small state-driven React screen instead of adding a routing or state-management dependency.

## Acceptance criteria

- The UI includes checking, PIN entry, incorrect PIN, temporary limit, name entry, and authenticated states.
- Text is friendly and contains no developer terminology.
- Buttons are large and touch-friendly.
- All controls support keyboard navigation and visible focus states.
- Meaningful status changes and errors use `aria-live`.
- User content is rendered only as text.
